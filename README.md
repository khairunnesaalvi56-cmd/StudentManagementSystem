# Student Management System

OOP Java Lab Project - Student Management System using Java OOP concepts.

## Features
- Add New Student
- View All Students
- Search Student by ID
- Delete Student
- Menu Driven Console Application

## Technologies Used
- Java
- OOP Concepts (Encapsulation, Class & Object, ArrayList)

## Project Structure
- Main.java - Main menu and program execution
- Student.java - Student class with attributes
- StudentManager.java - Logic for Add, View, Search, Delete

## How To Run
1. Open the project in VS Code / IntelliJ / Eclipse
2. Compile all .java files
3. Run Main.java
4. Choose option from menu
